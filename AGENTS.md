# Vibe-Workflow - Circus Portraits

## Objective

Transform `Vibe-Workflow` into a local Windows 11 application for producing 30 AI portraits: character sheets, reference images, versioned prompts, generation/upscale via API, node-based workflows, and a gallery. Custom desktop-oriented web app for LAN-only use.

## Conventions

- Shell: Windows PowerShell. Use `npm.cmd` (not `npm.ps1`).
- Python: `server\venv\Scripts\python.exe`.
- Backend binds to `127.0.0.1` only.
- UI text: French in ASCII without accents (e.g. "Creer", "Reessayer").
- Accent palette (taupe) defined as CSS vars in `client/app/globals.css`: `--color-accent: #615c50`, `-hover: #756f62`, `-soft: #b8b0a0`, `-focus: #9d9586`.
- Project data root: `PROJECTS_ROOT` env var, default `~/VibeWorkflowProjects` (`server/app/config.py`).
- Do NOT commit `client/AGENTS.md` and `client/CLAUDE.md` (auto-generated by `next dev`).
- Do not paste the legacy Liverpool data (in `D:\Projets\Migration_Outil_de_gestion`) into this repo; it is a separate confidential project.

## Verification Commands

- Backend tests: `server\venv\Scripts\python.exe -m pytest server\tests -q`
- Backend lint: `server\venv\Scripts\python.exe -m ruff check server`
- Client tests: `npm.cmd run test -w client`
- Client lint: `npm.cmd run lint -w client`
- Build: `npm.cmd run build -w client`
- Dev servers: backend `server\venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --app-dir server`; client `npm.cmd run dev -w client`.
